# Font licences

The four typefaces used on this site are self-hosted from this folder. All four are released
under the **SIL Open Font License, Version 1.1**, which explicitly permits self-hosting and
redistribution as part of a website.

The full licence text for each is included here, downloaded from each project's own source
repository — not paraphrased.

| Family | Used for | Licence file | Copyright line |
|---|---|---|---|
| **Cinzel** | Display headings, the big "45", numerals | `OFL-Cinzel.txt` | Copyright 2020 The Cinzel Project Authors |
| **Cormorant Garamond** | Serif ledes, scripture, pull quotes | `OFL-CormorantGaramond.txt` | Copyright 2015 The Cormorant Project Authors |
| **Great Vibes** | The "Anniversary" script in the hero | `OFL-GreatVibes.txt` | Copyright 2015 The Great Vibes Pro Project Authors |
| **Source Sans 3** | Body text, forms, navigation | `LICENSE-SourceSans3.md` | Copyright 2010–2024 Adobe, with Reserved Font Name 'Source' |

Only the **latin** subset of each family is included, to keep the download small. Google
serves one variable font file per family that covers every weight, which is why `fonts.css`
has more `@font-face` rules than there are files.

## Re-downloading them

If you ever need to refresh these, the source URLs are:

- Cinzel — https://fonts.google.com/specimen/Cinzel
- Cormorant Garamond — https://fonts.google.com/specimen/Cormorant+Garamond
- Great Vibes — https://fonts.google.com/specimen/Great+Vibes
- Source Sans 3 — https://fonts.google.com/specimen/Source+Sans+3
